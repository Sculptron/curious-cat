# Curious Cat

Curious Cat is a mobile-first, gamified, illustrated learning app for adult curiosity. A person types in a random question that's on their mind, and instead of it dying in a chatbot tab or getting buried in doom-scrolling, they're taken on a short, beautifully illustrated, game-like "expedition" that teaches them the answer — calibrated to what they already know, checked for understanding along the way, and capped with something worth saying out loud to someone else. The product splits teaching (an LLM-driven structured journey) from delight (illustration and game mechanics) as its core architectural bet.

This repo currently holds planning and design artifacts only — there is no working app here yet.

- **`docs/`** — the product brief, the UX/UI design handoff report, and the system prompt / payload engineering blueprint.
- **`design/`** — the interactive design system spec hub, a single-file reference covering the visual system across all mockup screens.
- **`mockups/`** — individual React (.tsx) mockups for each of the 10 core screens in the app's journey.
